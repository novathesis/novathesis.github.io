# novathesis.github.io

This repository does two things and nothing else:

1. **Redirects to [novathesis.org](https://novathesis.org)** — the project website, which replaced
   the content that used to live here.
2. **Hosts the brand assets** over https, so they can be referenced from GitHub profile and
   repository READMEs:

   | File | Use |
   |---|---|
   | [`novathesis-wordmark.svg`](novathesis-wordmark.svg) | Wordmark, outlined — needs no font |
   | [`novathesis-insignia-red.svg`](novathesis-insignia-red.svg) | Insignia, outlined |
   | `novathesis-insignia-square.png` | Avatar / Jekyll logo |
   | `novathesis-latex-logo-v5.*` | Previous logo, kept for old inbound links |

The wordmark is used by the [organization profile](https://github.com/novathesis). Brand sources live
in the `novathesis-artwork` repository; do not edit the copies here by hand.

Everything about the template itself — documentation, per-school repositories, the showcase — is at
**[novathesis.org](https://novathesis.org)**.
