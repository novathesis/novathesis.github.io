# NOVAthesis

**NOVAthesis** is a complete, actively maintained LaTeX template for MSc dissertations and PhD theses. It ships ready-to-use cover pages, spines and formatting rules for 20+ Portuguese higher-education institutions, on top of a modular LaTeX codebase with automated bibliography (`biblatex` + `biber`) and glossary (`bib2gls`) management.

👉 **Main development happens in a single repository:** **[joaomlourenco/novathesis](https://github.com/joaomlourenco/novathesis)**. That is where the source, the [wiki](https://github.com/joaomlourenco/novathesis/wiki), [issues](https://github.com/joaomlourenco/novathesis/issues), and [discussions](https://github.com/joaomlourenco/novathesis/discussions) live.

Each repository here is a clean, ready-to-use snapshot of the main template, pre-configured for a specific institution and kept automatically in sync. Using these lets you download only what you need for your school, with no unnecessary files included.

---

## Which repository do I need?

Find your institution below and use its repository. Each one is pre-configured for that school/department — download the ZIP, or clone it, and start writing.

**Not listed?** Use the **[main repository](https://github.com/joaomlourenco/novathesis)** instead and select your school in `0-Config/1_novathesis.tex` (see its [list of supported schools](https://github.com/joaomlourenco/novathesis#8-supported-schools) for the full, most up-to-date list).
